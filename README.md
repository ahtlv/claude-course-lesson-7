# Занятие 7: раздатка

Сегодня проверяем проект перед тем, как показывать его людям, и ускоряемся. Разбираемся, где
живут секреты и почему у статической страницы их быть не может. Ставим хук, который не
пускает агента к файлам с ключами. Прогоняем аудит безопасности по лендингу и MVP и чиним
найденное. Проверяем, чему мы доверили свой компьютер за курс. Потом два агента делают два
тикета одновременно, а вторая половина вечера это мастерская над твоим проектом.

Дорога курса: **найти идею → обсудить её → дать себя допросить → записать → разбить на задачи
→ делать по одной.** Сегодня «делать» идёт в два потока, а перед показом добавляется
«проверить на безопасность».

## Сначала проверка

В VS Code открой папку `work/StartUp/landing` и попроси Claude Code:

```text
Покажи открытые тикеты спеки MVP на GitHub и ссылки, по которым открываются лендинг и MVP.
```

## Промпты по порядку

| Шаг | Промпт | Что делает |
|---|---|---|
| 1 | [`protect-secrets.md`](prompts/protect-secrets.md) | Хук: агент не читает и не меняет файлы с секретами, отказ смотрим вживую |
| 2 | [`security-audit.md`](prompts/security-audit.md) | Аудит проекта по светофору: секреты, история git, библиотеки, личные данные. Ничего не правит |
| 3 | чиним 🔴 по одному | Промпт починки в конце `security-audit.md` |
| 4 | [`plugins-check.md`](prompts/plugins-check.md) | Кто проверял твои плагины: агент читает всё, что ты поставил за курс |
| 5 | [`parallel-tickets.md`](prompts/parallel-tickets.md) | Два тикета MVP одновременно, каждый агент в своей копии проекта |
| 6 | мастерская | Свой проект, свои тикеты, вопросы по ходу |

Промпты работают одинаково на Windows, macOS и Linux: агент сам определяет систему. На Windows
терминал только `cmd`, если открылся PowerShell, переключись.

## Что почитать

- [`secrets.md`](secrets.md): что такое `.env`, как `.gitignore` не пускает его на GitHub, почему
  ключ на странице видит любой и что делать, если ключ утёк. Живой пример:
  https://github.com/ahtlv/env-demo.
- [`hosting.md`](hosting.md): где потолок GitHub Pages, три ступени хостинга и какие подписки
  держать дальше.
- [`security-tools.md`](security-tools.md): библиотека скиллов по безопасности и cve-mcp для тех,
  кто хочет глубже.

## Домашнее задание

**К занятию 8, обязательно: проект готов к показу.**

1. **Безопасность.** Аудит по лендингу и MVP, все 🔴 закрыты, аудит прогнан повторно.
2. **MVP доведён.** Главный сценарий работает от начала до конца по ссылке. Оставшиеся тикеты
   делай параллельно или по одному. Не успеваешь всё? Спроси агента: «Какие тикеты можно не
   делать, чтобы главный сценарий работал?» Отрезать лишнее тоже работа.
3. **Показ.** Подготовь три минуты по [`show-prep.md`](show-prep.md) и отрепетируй с агентом.
   **Накануне занятия 8** кинь в чат курса две ссылки: лендинг и MVP.

Не довёл MVP? На финал всё равно приходи с историей: что задумал, где застрял, что понял.

**Для желающих:**

- ⭐ **Тайный покупатель.** Агент приходит на твою страницу как клиент и рассказывает, где
  чуть не ушёл: [`secret-shopper.md`](prompts/secret-shopper.md). Сыграй трёх разных людей.
- ⭐ **Проверь соседа.** Договорись в чате с кем-то из группы, обменяйтесь ссылками на
  публичные репозитории. Попроси агента скачать репозиторий соседа в отдельную папку и прогони
  там [`security-audit.md`](prompts/security-audit.md). Одну самую полезную находку отправь
  хозяину. Проверяем только того, кто согласился.
- ⭐ Не успел на занятии: [`plugins-check.md`](prompts/plugins-check.md).
- ⭐⭐ Поставь себе cve-mcp или скилл из библиотеки по безопасности:
  [`security-tools.md`](security-tools.md).

# Для тех, кто хочет глубже: инструменты безопасности

Промпт [`security-audit.md`](prompts/security-audit.md) закрывает всё, что нужно статической
странице. Когда у проекта появится сервер, зависимости и ключи, пригодятся инструменты
посерьёзнее. Оба проекта ниже открытые и бесплатные, автор Mahipal Jangra (GitHub `mukul975`),
специалист по кибербезопасности.

> Несмотря на название первого проекта, к компании Anthropic он отношения не имеет. Это
> проект сообщества.

## Библиотека скиллов: методички по безопасности

https://github.com/mukul975/Anthropic-Cybersecurity-Skills

Больше 750 скиллов, разложенных по направлениям: веб-приложения, контейнеры, API, безопасность
ИИ-агентов и другие. Каждый скилл это пошаговая процедура с готовыми командами, а не общие
советы. Агент берёт её и идёт по шагам, а не импровизирует.

Все 750 ставить не надо, большинство из них для специалистов по защите крупных компаний.
Возьми один-два под свою задачу:

```text
Скачай из репозитория github.com/mukul975/Anthropic-Cybersecurity-Skills папку скилла
skills/[имя] в мою папку скиллов в claude-config. Перед этим прочитай SKILL.md и скажи,
что он делает и не просит ли чего-то подозрительного.
```

С чего начать:

| Скилл | Когда пригодится |
|---|---|
| `auditing-mcp-servers-for-tool-poisoning` | перед установкой чужого MCP-сервера |
| `detecting-indirect-prompt-injection` | агент читает чужие страницы и документы |
| `implementing-secret-scanning-with-gitleaks` | проверка, что ключи не попадают в коммиты |
| `performing-security-headers-audit` | у сайта появился свой сервер или хостинг с настройками |

## cve-mcp: живая база уязвимостей прямо в чате

https://github.com/mukul975/cve-mcp-server

MCP-сервер, который подключает к Claude Code базы известных уязвимостей. Главное, что он
умеет: взять список библиотек проекта и сказать, в каких из них есть известные дыры. Ещё он
объясняет конкретную уязвимость (номер вида CVE-2020-11022), насколько она опасна и
пользуются ли ей злоумышленники на самом деле.

Для установки нужен Python 3.12, на Windows это отдельное приключение. Если хочешь
попробовать:

```text
Поставь MCP-сервер github.com/mukul975/cve-mcp-server по инструкции из его README.
Сначала прочитай код установки и скажи, что он будет делать на моём компьютере.
Ставь в отдельную папку с виртуальным окружением Python, глобально ничего не трогай.
```

Потом в новой сессии просто спроси: «проверь библиотеки этого проекта на уязвимости».

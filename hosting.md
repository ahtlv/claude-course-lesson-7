# Куда расти: хостинг и подписки

## Что умеет GitHub Pages и где его потолок

GitHub Pages бесплатно отдаёт готовые файлы: HTML, CSS, JavaScript, картинки. Для лендинга,
портфолио и MVP без сервера этого хватает с запасом.

Потолок наступает, когда проекту нужно что-то **хранить или скрывать**:

- принять заявку и сохранить её;
- отправить письмо или сообщение в Telegram от имени проекта;
- держать ключ к платному сервису;
- пускать на страницу только своих.

Всё это требует сервера: места, где код работает у тебя, а не в браузере посетителя. Ровно
в этот момент у проекта появляется `.env` (см. [`secrets.md`](secrets.md)).

## Три ступени

| Ступень | Что это | Когда переходить |
|---|---|---|
| **GitHub Pages** | готовые файлы, бесплатно | сейчас, пока нечего скрывать |
| **Хостинг с функциями** (Cloudflare Pages, Netlify, Vercel) | те же файлы плюс маленькие серверные функции, у которых есть свои секреты | первая форма, первый бот, первый ключ |
| **Свой сервер (VPS)** | арендованный компьютер в дата-центре, на нём что угодно | бот, база, несколько проектов, полный контроль |

Каждую ступень ставит агент, если попросить. С каждой ступенью на тебе больше ответственности:
обновления, резервные копии, безопасность. Начинай с нижней и поднимайся, только когда упёрся.

## Подписки

Курс шёл на Claude Pro. Что дальше, зависит от того, во что ты упираешься:

- **Упираюсь в лимиты Claude Code каждый день.** Следующая ступень это Max. Прежде чем
  платить больше, проверь привычки: новая сессия на каждый тикет, `/compact`, модель
  попроще для простых задач. Часто этого хватает.
- **Связка двух недорогих подписок против одной дорогой.** Например, Claude Pro и ChatGPT Plus
  (в нём есть агент Codex). Когда лимит одного кончился, работа идёт во втором, а память
  проекта (карта, спека, тикеты) лежит в файлах и на GitHub и подходит обоим.
- **Делаю не код.** Тексты, исследования, документы. Там подписка нужна под тот инструмент,
  которым пользуешься каждый день, а не под тот, что круче.

Цены и лимиты меняются часто, сверяйся с сайтами сервисов перед оплатой.
